cmp ==================================

ZF (Zero Flag): Set if the result is zero.
SF (Sign Flag): Set if the result is negative (most significant bit set).
OF (Overflow Flag): Set if the result overflows or underflows for signed operands.
CF (Carry Flag): Set if there is a borrow required from the most significant bit during subtraction.
Example:

mov eax, 10    ; eax = 10
cmp eax, 5     ; Compare eax with 5
After cmp eax, 5:

If eax is greater than 5, ZF will be clear (0).
If eax is equal to 5, ZF will be set (1).
If eax is less than 5, ZF will be clear (0) and CF will be set (1).
------------------------------
test =========================================

performs a bitwise **AND** operation between operand1 and operand2, storing the result in a temporary register (although this result is typically not used or stored).
The FLAGS register is updated based on the result of the AND operation, specifically:
ZF (Zero Flag): Set if the result of the AND operation is zero.
SF (Sign Flag): Set if the most significant bit of the result is set.
PF (Parity Flag): Set according to the parity (even or odd) of the least significant byte of the result.
Example:
-----------
mov eax, 10101010b    ; eax = 0xAA (binary)
test eax, 10000000b   ; Test if the most significant bit is set After test eax, 10000000b:
-----------
ZF will be set (1) if the result of eax AND 10000000b is zero.
SF will be set (1) if the most significant bit of eax AND 10000000b is set.
